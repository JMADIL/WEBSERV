## Overview

The `HttpResponse` class is the **data container and serializer** for HTTP responses generated by the web server.

```
┌─────────────────┐       fills       ┌──────────────────┐    serialize()    ┌───────────────┐
│ ResponseBuilder │──────────────────▶│   HttpResponse   │──────────────────▶│ Client Socket │
└─────────────────┘                   └──────────────────┘                   └───────────────┘
                                      • statusCode (200)                     "HTTP/1.1 200 OK\r\n
                                      • statusText ("OK")                    Content-Length: 13\r\n
                                      • headers map                          \r\n
                                      • body (vector<char>)                  Hello, world!"
```

### Key Responsibilities:
* Holds the HTTP status code and corresponding textual reason phrase (e.g., `200` $\rightarrow$ `"OK"`, `404` $\rightarrow$ `"Not Found"`).
* Stores HTTP headers as key-value pairs in a `std::map<std::string, std::string>`.
* Holds the response payload as a binary-safe `std::vector<char>` (supporting HTML, CSS, images, JSON, etc.).
* Produces the RFC-compliant raw byte string via `serialize()` to be sent directly over the client socket.
* Provides `reset()` to clean state when reusing the connection for HTTP Keep-Alive.

## Header Definition (`HttpResponse.hpp`)

```cpp
#ifndef HTTPRESPONSE_HPP
# define HTTPRESPONSE_HPP

# include <string>
# include <map>
# include <vector>

class HttpResponse
{
    public:
        int                                 statusCode;
        std::string                         statusText;
        std::map<std::string, std::string>  headers;
        std::vector<char>                   body;

        HttpResponse();
        ~HttpResponse();

        void        setStatus(int code);
        void        setHeader(const std::string &key, const std::string &value);
        void        setBody(const std::string &content);
        void        setBody(const std::vector<char> &content);
        std::string serialize() const;
        void        reset();

    private:
        static std::string _getStatusText(int code);
};

#endif
```

## Implementation File (`HttpResponse.cpp`)

```cpp
#include "HttpResponse.hpp"
#include <sstream>

HttpResponse::HttpResponse() : statusCode(200), statusText("OK")
{
}

HttpResponse::~HttpResponse()
{
}

void HttpResponse::setStatus(int code)
{
    statusCode = code;
    statusText = _getStatusText(code);
}

void HttpResponse::setHeader(const std::string &key, const std::string &value)
{
    headers[key] = value;
}

void HttpResponse::setBody(const std::string &content)
{
    body.assign(content.begin(), content.end());
}

void HttpResponse::setBody(const std::vector<char> &content)
{
    body = content;
}

std::string HttpResponse::serialize() const
{
    std::ostringstream oss;

    // 1. Status Line: HTTP/1.1 <code_as_int> <statusText>\r\n
    oss << "HTTP/1.1 " << statusCode << " " << statusText << "\r\n";

    // 2. Prepare headers (check if Content-Length already set, otherwise add it)
    bool hasContentLength = false;
    for (std::map<std::string, std::string>::const_iterator it = headers.begin();
         it != headers.end(); ++it)
    {
        if (it->first == "Content-Length" || it->first == "content-length")
        {
            hasContentLength = true;
            break;
        }
    }

    if (!hasContentLength)
    {
        oss << "Content-Length: " << body.size() << "\r\n";
    }

    // 3. Write all headers
    for (std::map<std::string, std::string>::const_iterator it = headers.begin();
         it != headers.end(); ++it)
    {
        oss << it->first << ": " << it->second << "\r\n";
    }

    // 4. Header-body separator (CRLF)
    oss << "\r\n";

    // 5. Append body
    std::string responseString = oss.str();
    if (!body.empty())
    {
        responseString.append(&body[0], body.size());
    }

    return responseString;
}

void HttpResponse::reset()
{
    statusCode = 200;
    statusText = "OK";
    headers.clear();
    body.clear();
}

std::string HttpResponse::_getStatusText(int code)
{
    switch (code)
    {
        // 2xx Success
        case 200: return "OK";
        case 201: return "Created";
        case 202: return "Accepted";
        case 204: return "No Content";

        // 3xx Redirection
        case 301: return "Moved Permanently";
        case 302: return "Found";
        case 304: return "Not Modified";

        // 4xx Client Errors
        case 400: return "Bad Request";
        case 401: return "Unauthorized";
        case 403: return "Forbidden";
        case 404: return "Not Found";
        case 405: return "Method Not Allowed";
        case 408: return "Request Timeout";
        case 413: return "Payload Too Large";
        case 414: return "URI Too Long";
        case 431: return "Request Header Fields Too Large";

        // 5xx Server Errors
        case 500: return "Internal Server Error";
        case 501: return "Not Implemented";
        case 502: return "Bad Gateway";
        case 504: return "Gateway Timeout";
        case 505: return "HTTP Version Not Supported";

        default:  return "Unknown Status";
    }
}
```

## Detailed Breakdown of Methods

### 1. Constructor: `HttpResponse()`
```cpp
HttpResponse::HttpResponse() : statusCode(200), statusText("OK")
```
* **Purpose**: Initializes the response object with safe, sensible defaults.
* **Mechanism**:
  - Sets `statusCode` to `200` and `statusText` to `"OK"`.
  - `headers` map and `body` vector are default-initialized as empty containers.

---

### 2. Destructor: `~HttpResponse()`
```cpp
HttpResponse::~HttpResponse()
```
* **Purpose**: Clean destruction of object instances.
* **Mechanism**: Standard empty destructor. Member objects (`std::string`, `std::map`, `std::vector`) deallocate their internal dynamic memory automatically via RAII.

---

### 3. `void setStatus(int code)`
```cpp
void HttpResponse::setStatus(int code)
{
    statusCode = code;
    statusText = _getStatusText(code);
}
```
* **Purpose**: Updates both the numeric status code and its standardized reason phrase in a single call.
* **Why it matters**: Calling `setStatus(404)` automatically sets `statusText = "Not Found"`, ensuring consistency throughout the HTTP status line.

---

### 4. `void setHeader(const std::string &key, const std::string &value)`
```cpp
void HttpResponse::setHeader(const std::string &key, const std::string &value)
{
    headers[key] = value;
}
```
* **Purpose**: Sets or updates an HTTP header (e.g., `setHeader("Content-Type", "text/html")`).
* **Mechanism**: Uses `operator[]` of `std::map`. If the key already exists, its value is updated; if it does not exist, a new key-value pair is inserted.

---

### 5. `void setBody(...)` (String and Vector Overloads)
```cpp
void HttpResponse::setBody(const std::string &content)
{
    body.assign(content.begin(), content.end());
}

void HttpResponse::setBody(const std::vector<char> &content)
{
    body = content;
}
```
* **Purpose**: Populates the response body from either a `std::string` (convenient for HTML/JSON text) or a `std::vector<char>` (for binary images, downloads, etc.).
* **Binary Safety**: Storing the body as `std::vector<char>` ensures files containing null bytes `\0` (e.g., `.png`, `.jpg`, `.pdf`) are never truncated.

---

### 6. `std::string serialize() const`
```cpp
std::string HttpResponse::serialize() const
```
* **Purpose**: Assembles the complete HTTP/1.1 wire-format response string ready to be written to the socket via `send()`.
* **Step-by-step Execution**:
  1. **Status Line**: Emits `HTTP/1.1 <statusCode> <statusText>\r\n`.
  2. **Automatic `Content-Length`**: Checks whether a `Content-Length` header was explicitly supplied. If not, automatically calculates and appends `Content-Length: <body.size()>\r\n`.
  3. **Header Fields**: Iterates through the `headers` map and formats each entry as `Key: Value\r\n`.
  4. **CRLF Delimiter**: Adds the mandatory empty line `\r\n` separating headers from body.
  5. **Body Append**: Appends raw bytes from `body` using `std::string::append(&body[0], body.size())`, guaranteeing binary safety.

---

### 7. `void reset()`
```cpp
void HttpResponse::reset()
```
* **Purpose**: Cleans the response container so that the client connection can be reused for the next HTTP request under **HTTP Keep-Alive**.
* **Mechanism**: Resets status to `200 OK`, clears the header map, and empties the body vector without destroying the enclosing object.

---

### 8. `std::string _getStatusText(int code)`
```cpp
std::string HttpResponse::_getStatusText(int code)
```
* **Purpose**: Maps standard HTTP status codes to their official RFC reason phrases.
* **Supported Codes**:
  * **2xx (Success)**: `200 OK`, `201 Created`, `202 Accepted`, `204 No Content`.
  * **3xx (Redirection)**: `301 Moved Permanently`, `302 Found`, `304 Not Modified`.
  * **4xx (Client Errors)**: `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`, `405 Method Not Allowed`, `408 Request Timeout`, `413 Payload Too Large`, `414 URI Too Long`, `431 Request Header Fields Too Large`.
  * **5xx (Server Errors)**: `500 Internal Server Error`, `501 Not Implemented`, `502 Bad Gateway`, `504 Gateway Timeout`, `505 HTTP Version Not Supported`.

## C++98 Compliance Verification

* **Formatting via `std::ostringstream`**: Used instead of C++11 `std::to_string()`.
* **Explicit Iterators**: `std::map<std::string, std::string>::const_iterator` used instead of `auto`.
* **Standard Includes**: `<string>`, `<map>`, `<vector>`, `<sstream>`. All standard C++98 libraries.
* **Include Guards**: Standard `#ifndef HTTPRESPONSE_HPP` avoids compiler-specific `#pragma once`.
